

# Estructura corregida

El proyecto fue reorganizado para que cada pantalla tenga su propia carpeta con HTML, CSS y JS:

- `index/` → `index.html`, `index.css`, `index.js`
- `carrito/` → `carrito.html`, `carrito.css`, `carrito.js`
- `checkout/` → `checkout.html`, `checkout.css`, `checkout.js`
- `confirmacion/` → `confirmacion.html`, `confirmacion.css`, `confirmacion.js`
- `login/` → `login.html`, `login.css`, `login.js`
- `pedidos/` → `pedidos.html`, `pedidos.css`, `pedidos.js`
- `producto/` → `producto.html`, `producto.css`, `producto.js`
- `admin/` → sus HTML, CSS y JS
- `Imagenes/` → imágenes de los productos

Las rutas de imágenes y enlaces entre páginas fueron ajustadas para esta estructura.

Para abrir la página principal, abre `index/index.html` con Live Server.
